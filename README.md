# Financial Fraud Detection & Transaction Risk Analysis — Excel Dashboard

## 📊 Project Overview

**Financial Fraud Detection & Transaction Risk Analysis** is an interactive Excel dashboard designed to monitor transaction activity, analyze fraud patterns, and identify high-risk transactions.

The dashboard provides a consolidated view of transaction volume, fraud cases, fraud rate, transaction amount, high-risk transactions, payment methods, transaction types, locations, and risk categories.

It also includes interactive filters for **Month, Risk Category, Transaction Type, Customer Location, and Payment Method**, allowing users to explore the transaction data from different perspectives.

> **Dashboard tool:** Microsoft Excel  
> **Project type:** Data Analysis / Business Intelligence / Dashboarding  
> **Domain:** Financial Fraud Detection & Transaction Risk Analysis

## 🎯 Project Objectives

The main objectives of this dashboard are to:

- Monitor overall transaction activity.
- Identify fraudulent and non-fraudulent transactions.
- Calculate the overall fraud rate.
- Analyze high-risk transactions.
- Compare fraud activity across payment methods.
- Analyze fraud patterns by transaction type.
- Examine fraud distribution across risk categories.
- Compare transaction activity across customer locations.
- Track monthly fraud trends.
- Analyze transaction amounts for fraudulent and non-fraudulent transactions.
- Provide interactive filtering for focused analysis.

## ⚠️ Important Note

The dashboard is a data-analysis and visualization project based on the underlying transaction dataset.

The classifications shown in the dashboard, including **fraud, risk category, and high-risk transactions**, should be interpreted as classifications contained in the dataset rather than as independent verification of real-world fraudulent activity.

The dashboard is intended for **analytical exploration and demonstration of Excel dashboarding techniques**.

## 🚀 How to Use the Dashboard

1. Download or clone this repository.
2. Open the Excel workbook from the `dashboard` folder.
3. Enable content or editing if Excel displays a security prompt and you trust the file.
4. Open the dashboard worksheet.
5. Use the available filters.
6. Select a month, risk category, transaction type, location, or payment method.
7. Review the KPI cards and charts to analyze the filtered results.
